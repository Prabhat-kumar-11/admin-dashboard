### ✅ MongoDB SCHEMAS (Complete)

1. **User Schema**
   - name, email, password (hashed)
   - role: Admin | User
   - status: Active | Inactive
   - lastLogin tracking

2. **Task Schema**
   - title, description
   - status: Pending | In Progress | Completed
   - priority: Low | Medium | High
   - dueDate, createdBy, assignedTo relationships

3. **ActivityLog Schema**
   - userId, action, description

   - Automatic timestamp tracking

### ✅ API ENDPOINTS

**Authentication** (`/api/auth`):
- POST /register - New user registration
- POST /login - User login with activity log
- GET /me - Get current user info
- POST /logout - User logout

**Tasks** (`/api/tasks`):
- GET / - Get user's tasks (paginated)
- POST / - Create new task
- GET /:id - Get single task
- PUT /:id - Update task (ownership verified)
- DELETE /:id - Delete task (ownership verified)

**Admin** (`/api/admin`):
- GET /users - Get all users
- DELETE /users/:id - Delete user
- PUT /users/:id/status - Update user status
- GET /tasks - Get all tasks
- DELETE /tasks/:id - Delete any task
- GET /activity-logs - Get activity logs
- GET /analytics - Get analytics data

## 🚀 QUICK START

### Prerequisites
- Node.js v14+
- MongoDB
- Git

### Installation
```bash
# Clone and setup
git clone https://github.com/Prabhat-kumar-11/admin-dashboard.git
cd adminDashboard
npm run install-all

# Configure environment
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# Start services
# Terminal 1:
npm run dev-backend

# Terminal 2:
npm run dev-frontend

# Access: http://localhost:3000
```
